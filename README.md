# 🚀 Proyecto de Aprendizaje en Godot Engine 
## Version 0.2.0

Este repositorio es un espacio de trabajo y aprendizaje dedicado a explorar las capacidades de **Godot Engine** (versión 4.x).

El objetivo principal es seguir y aplicar los conocimientos obtenidos de tutoriales específicos para consolidar mi comprensión del desarrollo de juegos con Godot, su lenguaje de scripting **GDScript**, y la implementación de sistemas 2D y 3D.

---

## 📚 Fuentes de Aprendizaje (Tutoriales Seguidos)

Este proyecto se basa y avanza siguiendo los siguientes recursos de la comunidad de Godot Land / DevMark:

### 1. Godot Land (Guías y Artículos)
Se están siguiendo los tutoriales y guías disponibles en **[https://godot.land/](https://godot.land/)**.

* **Objetivo de Aprendizaje:** Comprender la documentación fundamental de las herramientas, el sistema de nodos, y flujos de trabajo específicos de la plataforma.

### 2. Curso de Nodos de Godot (YouTube - DevMark)
Se está siguiendo la lista de reproducción detallada sobre los fundamentos de Godot 4: **[Curso Nodos de Godot](https://www.youtube.com/watch?v=f0POV9ZyQhU&list=PLgI0I_tQQ38I1-T1D2d--PTpYl4TEk6m2)**.

* **Objetivo de Aprendizaje:** Dominar el sistema de Nodos y Escenas, la estructura fundamental de Godot, y la implementación práctica de sistemas de juego comunes.

---

## 🧩 Estructura del Proyecto

El código está organizado de manera que cada carpeta o escena principal corresponde, en la medida de lo posible, a un tutorial o concepto clave aprendido.

* **`/scenes`:** Contiene las escenas principales del juego/ejemplo.
* **`/scripts`:** Contiene el código GDScript asociado.
* **`/assets`:** Contiene los recursos gráficos, de audio, etc. (Si aplica)

### 📌 Ejemplos de Contenido Actual (¡Actualiza esta sección!)

* **`01_NodosEscenas/`**: Lección inicial sobre el uso de `Node` vs. `Node2D` y la estructura de un árbol de escena (Basado en el primer video del curso).
* **`Movement2D/`**: Implementación de `CharacterBody2D` y la función `_physics_process()`.
* **`SignalsAndSlots/`**: Uso de señales para comunicación entre nodos.

## 💻 Requisitos

Para clonar y ejecutar este proyecto, necesitarás:

* **Godot Engine:** Versión **4.x** (Se recomienda usar la versión más reciente para compatibilidad con los tutoriales).
* **Sistema Operativo:** Windows, macOS o Linux.

### Ejecución

1.  Clona este repositorio:
    ```bash
    git clone [TU_URL_DE_GITHUB]
    ```
2.  Abre Godot Engine.
3.  Haz clic en **"Importar Proyecto"** y selecciona el archivo `project.godot` dentro de la carpeta clonada.
4.  Ejecuta la escena principal (normalmente presionando **F5** o el botón "Play").
